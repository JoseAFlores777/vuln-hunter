La barrera de mayor severidad —la aprobación humana del patch— estaba atada al working tree (git diff HEAD) en vez de al índice staged que realmente se commitea. Permitía aprobar un fix limpio y luego commitear un backdoor con el hash de aprobación intacto. Cerrada.

Confirmado limpio: el panel React no tiene XSS (JSX auto-escapa, sinks por textContent); report.py escapa todo valor del ledger; y el allowlist tools: del red-team ya impide escritura/red sin depender de disallowedTools.

§ 02Metodología

  • Lectura completa del código ejecutable (hooks, scripts, panel, CI) e inventario del repo.
  • Workflow de 57 sub-agentes sobre 8 dimensiones, cada hallazgo pasado por un verificador adversarial que debía refutarlo o confirmarlo y corregir la fix.
  • Verificación de la semántica real de Claude Code (docs en vivo): tools: es allowlist enforced; Bash(cmd:*) granular no aplica en frontmatter de agentes; los hooks PreToolUse aplican a subagentes; exit 2 deniega.
  • Remediación con prueba de cada fix: el bypass debe bloquear, el caso legítimo pasar.

§ 05Bajo / informativo (remediados)

  • Hooks: fail-closed en entrada ilegible; regex de brute-force anclada a invocación; patrones ofensivos ampliados; rutas de estado ancladas a CLAUDE_PROJECT_DIR; matcher de deploy ampliado.
  • Python: migrate purga findings no-dict; escritura atómica; status.py robusto; activity.py protege type/ts; resume rutea solo-intel a triage.
  • Report: sin --enable-local-file-access; clamp de margen.
  • Shell: run-scan.sh con npx --no-install; cache chmod 700.
  • Panel: React/ReactDOM/Babel pineados a versión exacta + SRI + crossorigin.
  • CI: acciones pineadas por SHA + dependabot.yml.
  • Schema: schema_version a enum + skill a 1.2 + test de lockstep. plugin.json re-declara hooks.

§ 06Descartados (falsos positivos verificados)

  • Panel DOM-XSS: limpio. JSX auto-escapa; tooltip por textContent; href con encodeURIComponent/constantes; sin dangerouslySetInnerHTML.
  • Allowlist del red-team: es la barrera real; aun ignorando disallowedTools, el agente no tiene Write ni Bash de red.
  • Otros: fixer omite git commit (correcto); VULN_ACTIVITY es ruta del operador; cache-key/url y run-scan target no explotables en contexto.

§ 07Verificación

Cada fix probada: el bypass bloquea, el caso legítimo pasa.

  • Suite: python3 -m unittest discover -s tests → 84 OK (53 + 31 nuevos).
  • Hook: bloquea re-staging post-aprobación (backdoor), -C/-c/commit-tree, commit -a, deploy con gate, ofensivos; permite commit aprobado y git status.
  • Panel: sirve solo en loopback (Host bueno→200, rebind→421). intel-cache rechaza http/host no oficial/arg-injection/file://. deploy-gate bloquea KEV/EPSS y limpia al parchear.
  • Sanidad: bump-version --check, py_compile, bash -n, json.load de todos los artefactos OK.
